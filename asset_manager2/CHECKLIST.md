# asset_manager2 — 되살릴 기능 목록

asset_manager(폰 우선 PWA)를 표 하나로 새로 만든 뒤, 원래 있던 기능을 하나씩
가져오며 지우는 목록. 대화에만 있던 것을 파일로 옮긴 것이라 여기가 원본이다.
원본은 `~/web_service/asset_manager/src-lilak/App.jsx`(4,089줄), 여기는 `src-lilak/App.jsx`.

데이터가 사는 곳이 다르다는 것만 기억하면 된다: 원본은 브라우저
`localStorage`(`cens.*`), 여기는 포털이 보관하는 프로젝트 문서 하나
(`/api/data` → `{assets, records, locations, types, settings}`).
