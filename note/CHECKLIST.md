- [x] 파일 per 노트 (YAML 머리말 + 마크다운), Obsidian에서 바로 열리는 폴더
- [x] 목록: date · title · tags · 할 일 · words · 첫 줄, 정렬·필터·선택
- [x] 편집기: 버튼은 제목 위, 제목 옆 접기에 날짜·파일 이름·머리말 키, 나머지는 전부 본문
- [x] 본문: **Milkdown WYSIWYG** — 표시가 남지 않고, 편집 동작은 시스템 것 그대로
- [x] 체크박스는 본문에서 눌러서 체크 (CSS로 그리고 노드를 뒤집는다)
- [x] `[] ` 만으로 체크리스트 시작 (목록 밖에서도)
- [x] 왼쪽에 막대 칸, 줄마다 막대 하나 (전부 같은 x), 커서가 있는 줄만 색칠
- [x] 편집 칸 둘 — 칸이 선 반대쪽을 가리키는 화살표로 노트를 보내 좌우로 나란히 본다
- [x] 탭 줄 두 번 눌러 전체 너비
- [x] 태그: **본문에만** `#태그` (Obsidian 표기). 제목 `# `과 공백으로 갈린다
- [x] 인쇄 화면은 kit의 `Markdown`으로 렌더 (GFM 체크박스)
- [x] todos 탭 — 모든 노트의 체크박스를 모으고, 체크하면 그 줄을 고쳐 저장
- [x] tags 탭 — 태그와 개수, 눌러서 그 태그의 노트 탭
- [x] 검색 — 제목·태그는 즉시, 본문은 서버에 물어서 걸린 줄을 보여줌
- [x] 템플릿 — `templates/` 폴더의 노트가 곧 템플릿
- [x] 미리보기 — 고른 노트를 새 탭에 읽히는 모습으로, `#태그`는 태그 모양으로.
